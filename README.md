# Astra-Electron

Astra client turned into an exe

## How to use

The first step is to download it. You can find the downloads in the releases tab on the right. There are 2 actual ways to use it after you downloaded listed below.

### Use it portably (not installing it on the system)

1. Download it
2. Look in [your os here]-unpacked and open the executable (for linux im pretty sure you have to open it in terminal)

### Install it

1. Download it
2. Run the installer
3. Open it from the start menu or look in the place where programs are installed for your os (Program Files for windows)

## Notes

- To close you have to end task by force using task manager.
- Newer versions' local save data (stored in %currentuser%/appdata/roaming/eagler_1.8) incompatible with older versions
