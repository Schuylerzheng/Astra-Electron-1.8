# Astra-Electron

Astra client turned into an exe

## How to use

The first step is to download it. You can find the downloads in the releases tab on the right, and download the one for your os without the blockmap at the end.. There are 2 actual ways to use it after you downloaded listed below.

### Use it portably (not installing it on the system)

1. Download the portable archive for your OS
2. Then run the executable in it

### Install it

1. Download the executable for your os
2. Run it
3. Open it from the start menu or look in the place where programs are installed for your os (Program Files for windows)

## Notes

- To close you have to end task by force using task manager.
- Newer versions' local save data (stored in %currentuser%/appdata/roaming/eagler_1.8) incompatible with older versions
